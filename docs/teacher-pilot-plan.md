# 教师试用：教学内容创作工作台

分支：`feat/teacher-authoring-studio`。起点：`2ffd504`。目标不是增加一个聊天框，而是让老师从需求得到可编辑、可追溯、可打印的教学作品。

## 验收范围（全部保留，未实现项不能算完成）

1. 自然语言出卷：解析学段、学科、范围、题型、数量、分值、时长和难度；从当前教师题库选题；缺题明确展示；保存到现有组卷编辑器，学生卷解答题仍至少占半页。
2. 整卷变式：选择原卷，保持题目目标、题型与分值映射，逐题调用现有变式审校流程，失败可重试；原题与变式可对照，未经确认不冒充已审核题。
3. 讲义：先生成可编辑大纲，再按章生成知识讲解、公式条件、例题讲解、分层练习和答案；三角函数按课程范围形成覆盖矩阵，不能只写章节名就计为覆盖。
4. 校本/教辅：从老师指定的资料中逐章筛题；记录来源、选入理由、难度梯度、重复与缺口；长任务按章持久化，刷新/重启可恢复，教师可替换题目。
5. 标签与检索：知识点稳定 ID + 别名 + 层级；题型、方法、能力、难度分开；模型标签有依据、有版本、可人工纠正；题目修改使旧标签失效；检索严格限制租户/学科/学段/来源，显示命中原因，不能把宽泛关键词当成已验证覆盖。
6. 交付质量：真实模型试跑与教师视角流程；真实 PDF 逐页检查；保存恢复、跨租户、失败重试和超大题库回归；新分支提交。不能用单元测试代替这些验收。

## 资料与产品判断

- [教育部课程教材研究所：高中课程标准下载目录](https://www.ictr.edu.cn/download_center/put.html)，数学 2017 年版 2020 年修订。已下载官方附件到本地研究缓存并提取文本。三角函数范围包含角与弧度、定义与性质、同角关系、恒等变换、实际应用；解三角形单独关联。由此建立可逐项检查的知识树，不把教材某一章的标题当作完整范围。
- [教育部教育考试院：2024 年数学适应性测试](https://www.neea.edu.cn/html1/report/2401/426-1.htm)，明确命题依据该版课标，可作为题型结构研究资料；它不能证明某一地区下一年的考试范围。试用时保存教师选择的教材、地区与目标考试。
- 本地证据：`lib/education-taxonomy.ts` 目前是粗粒度字符串标签；`getApprovedQuestions` 默认最多 2000 题；组卷缺少模型规划、覆盖矩阵和成册内容模型；变式已有计划/生成/复核流程，可以复用。

工程判断：先建立稳定知识目录、带证据标签、可解释检索、作品大纲和持久化章节，再接自动选题与讲解。整本教辅不能一次塞入模型，也不能只取最近 2000 道题。每章保留候选、选入理由与缺口，最后按作品级规则验证覆盖和重复。

## 实施记录

- 待验证：上述六项完整流程，当前尚不能宣称试用就绪。

### 第一阶段实际落地

- `/studio`：自然语言提交试卷/讲义/教辅大纲；选择当前学科、学段内资料与必覆盖范围；大纲保存、题量编辑、版本冲突保护、最近作品恢复、候选供给检查。
- Worker 持久化规划任务，租约超时才恢复；过期 worker 结果不能覆盖新租约；模型失败可手动重试。当前只执行大纲任务，还没有执行章节正文任务。
- 高中三角函数 14 个细粒度考点及解三角形关联节点；其他学段学科沿用原目录。知识点、方法、能力、难度分开，难度是教学估计而非统计得分率。
- 模型标签有依据、置信度和调用追踪；教师可编辑确认；原题、选项、答案、解析、题图或目录版本变化后旧标签失效。模型不能覆盖当前版本的教师确认标签。
- 检索遍历全部当前范围已审核题目，严格限制租户与资料；区分确认考点、建议考点、原有字符串标签和文字命中。难度筛选与覆盖统计不把关键词命中当作确认。
- 真实题库只读本地性能测量：20697 道高中题，周期查询命中 366 道；读取 1982 ms，排序 182 ms。只输出统计，没有外传题目。覆盖检查按考点/题型缓存重复查询。
- 已加入下一阶段正文/审校的数据契约与测试：知识讲解、公式条件、误区、例题讲解、逐组配额、缺题记录、逐项审校；尚未接到生成服务，不能当成正文功能已完成。
- 当前 3050 继续使用原生产构建，试用分支使用 `JIANTI_NEXT_DIST_DIR=tmp/teacher-pilot/next` 独立构建与隔离测试数据库，未迁移正式数据。测试过程不连接外部模型。
