# 教师试用：教学内容创作工作台

分支：`feat/teacher-authoring-studio`。起点：`2ffd504`。目标不是增加一个聊天框，而是让老师从需求得到可编辑、可追溯、可打印的教学作品。

## 验收范围（全部保留，未实现项不能算完成）

1. 自然语言出卷：解析学段、学科、范围、题型、数量、分值、时长和难度；从当前教师题库选题；缺题明确展示；保存到现有组卷编辑器，学生卷解答题下方单独至少留半页作答，题干与图片不抵扣。
2. 整卷变式：选择原卷，保持题目目标、题型与分值映射，逐题调用现有变式审校流程，失败可重试；原题与变式可对照，未经确认不冒充已审核题。
3. 讲义：先生成可编辑大纲，再按章生成知识讲解、公式条件、例题讲解、分层练习和答案；三角函数按课程范围形成覆盖矩阵，不能只写章节名就计为覆盖。
4. 校本/教辅：从老师指定的资料中逐章筛题；记录来源、选入理由、难度梯度、重复与缺口；长任务按章持久化，刷新/重启可恢复，教师可替换题目。
5. 标签与检索：知识点稳定 ID + 别名 + 层级；题型、方法、能力、难度分开；模型标签有依据、有版本、可人工纠正；题目修改使旧标签失效；检索严格限制租户/学科/学段/来源，显示命中原因，不能把宽泛关键词当成已验证覆盖。
6. 交付质量：真实模型试跑与教师视角流程；真实 PDF 逐页检查；保存恢复、跨租户、失败重试和超大题库回归；新分支提交。不能用单元测试代替这些验收。

## 资料与产品判断

- [教育部课程教材研究所：高中课程标准下载目录](https://www.ictr.edu.cn/download_center/put.html)，数学 2017 年版 2020 年修订。已下载官方附件到本地研究缓存并提取文本。三角函数范围包含角与弧度、定义与性质、同角关系、恒等变换、实际应用；解三角形单独关联。由此建立可逐项检查的知识树，不把教材某一章的标题当作完整范围。
- [教育部教育考试院：2024 年数学适应性测试](https://www.neea.edu.cn/html1/report/2401/426-1.htm)，明确命题依据该版课标，可作为题型结构研究资料；它不能证明某一地区下一年的考试范围。试用时保存教师选择的教材、地区与目标考试。
- 本地证据：`lib/education-taxonomy.ts` 目前是粗粒度字符串标签；`getApprovedQuestions` 默认最多 2000 题；组卷缺少模型规划、覆盖矩阵和成册内容模型；变式已有计划/生成/复核流程，可以复用。

工程判断：先建立稳定知识目录、带证据标签、可解释检索、作品大纲和持久化章节，再接自动选题与讲解。整本教辅不能一次塞入模型，也不能只取最近 2000 道题。每章保留候选、选入理由与缺口，最后按作品级规则验证覆盖和重复。

- Worker 持久化规划任务，租约超时才恢复；过期 worker 结果不能覆盖新租约；模型失败可手动重试。本阶段先接通大纲，第二阶段已继续接入章节任务（见下）。

### 第二阶段实际落地（2026-10-24）

- 持久化逐章候选比较→选题→带原题图编写→独立审校；每章最多 30 题，整本最多 1000 题。串行章节避免同一本书并发重复选题；跨章 ID 与规范化题干去重；按目标难度优先提供已标注候选。
- 支持暂停后续章节、继续、单章重试、仅重新审校。正文先存检查点，审校失败不丢正文；运行租约定期续期，旧 worker 不能保存结果。结构化返回不合格时，带具体校验错误重试一次，不降低要求。
- 教师可编辑知识讲解、公式与条件、误区、例题详解、小结；可从限定资料替换/补充题目，保存时重新读取可信原题并检查版本、题型、重复。未保存修改有离页保护；正在编写时要求先暂停并等当前章结束再编辑。
- 逐章采用后才允许正式导出；缺题不可直接采用。审校有问题时需修订或记录具体人工核对说明。源题内容、审核状态或范围变化会阻止采用/导出。
- 试卷可以发布到现有组卷器，保留题序、分值与半页作答下限；修订作品会生成新试卷版本，保留旧卷。
- 学生/教师版讲义预览与 PDF：目录、知识正文、公式条件、例题详解、练习与半页作答、章末回顾；教师版追加练习答案。短讲义不强制独立封面，长书保留目录分页，末题与小结一起排。打印能力令牌隔离于试卷令牌，只嵌入该作品题图，不能访问通用文件接口。
- 真实模型暴露两类问题：用简单题占高难度缺口、同考点拆成重复结构项。约束反馈和明确结构要求后能生成完整正文并诚实保留高难度缺口。
- 真实正文人工抽查发现通用模型审校漏判：负周期、正切定义域、绝对值函数的错误表述。增加周期专题 4 项明确核查，每项要求引用原文；真实重新审校已指出上述问题，作品保持 `needs_review`，未被采用或正式导出。**不能据此声称真实讲义质量已经通过**。其他考点仍需扩展核查和真实验收。
- 证据：276 项单元回归通过；章节服务另外验证原题图片送入编写/审校、打印内嵌图片、源题变化、版本冲突、暂停恢复、审校失败检查点、发布新版本和打印令牌隔离。浏览器已跑通完整章节编辑采用及两版真实 PDF；所有页已用 Poppler 渲染检查。日志、PDF、截图在 `tmp/teacher-pilot/`，真实模型试验在 `tmp/teacher-pilot/live-chapters-1792775659924/`。这只证明小样本流程，不是全书验收。

### 第五阶段：教学顺序、作品覆盖与单章调整（2026-10-24）

- 讲义/教辅大纲必须采用具体考点，每个考点都有例题和练习配额；不能只在一个章节写多个考点，却只给其中一个配题。作品中要讲的先备知识必须排在依赖它的知识之前，章内知识讲解也按计划顺序排列。范围外的先备知识单独显示，提醒教师核对学生基础。
- 大纲结构或教学顺序校验不通过时，带具体错误反馈修正一次；仍不通过保留失败，不降低要求。自然语言的数字/分数等独立约束审计仍未完成，不能将结构校验视为对全部教师要求的理解保证。
- 候选供给使用全量匹配与最大匹配分配，分别计算已确认标签、含模型建议标签的去重供给；同题 ID 和相同规范化题干不能同时充当两组配额。小规模穷举验证匹配数，另验证超过 100 个候选不会受搜索分页截断。
- 整份作品覆盖表区分计划配额、已保存选题、知识正文和教师采用；显示目标难度，不冒充实测难度或逐题确认标签。原题变更/失效及重复引用不算有效覆盖；正式导出重新校验来源与作品覆盖状态。
