# 功能实现清单

本文记录拾题当前已经落地的产品能力和关键技术行为。面向使用者的项目介绍与启动方式请返回 [README](../README.md)。

## 试卷导入与本地存储

- 仅接收 PDF 试卷，支持一次选择最多 100 份文件。
- 浏览器使用 PDF.js 逐页高清渲染，按“渲染一页、落盘一页、释放一页”控制内存占用。
- 原卷在页面渲染前立即预登记；切换页面或模型尚未配置时，原卷和已经生成的分页图仍会保留。
- 原卷、分页图和后续裁剪图保存到本地文件目录，并使用 SHA-256 去重和校验。
- 上传前只需选择全局学段与学科；年份、考试类型、地区和学校从卷头推测，可在试卷详情中修正。
- SQLite 自动建库并执行幂等兼容升级。

## 动态并发与可靠识别队列

- 教师可随时把“同时处理试卷”设置为 1–100 份；设置会持久化，并同步影响浏览器渲染、上传和服务端识别队列。
- 提高并发后会立即领取更多任务；降低并发不会中断正在处理的试卷，新任务会等待运行数收敛到新上限。
- 支持像下载器一样“全部暂停”和“全部开始”；恢复时会清除长退避与失败计数，并立即重排所有未完成页面。
- 连续 3 次识别请求失败会触发全局熔断，自动暂停同一教师空间内的全部识别任务，避免大量试卷进入超长退避。
- 页面和文档任务持久化为 `queued`、`processing`、`retry_wait`、`paused`、`complete` 或 `failed`，并记录尝试次数、下次重试时间、租约和错误。
- 任务领取使用租约与心跳；服务进程重启后会自动回收过期任务并续跑。
- 每页抽题使用幂等键和独立事务，成功一页就立即保存题目、坐标、模型原始响应和完成状态，后续只重试未完成页。
- 每份试卷保留其实际绑定的模型配置；工作台、上传进度和审核页会直接显示模型名称，审核页还会按当前页面显示真正执行该页识别的模型。
- 超时、网络错误、429、5xx 和网关拥挤会遵循 `Retry-After` 或指数退避，最多尝试 8 次。
- OpenAI Responses 的结构化参数被兼容网关拒绝时会自动降级一次。

## 题目提取与人工审核

- 保存题目 JSON、LaTeX、页面坐标、题图坐标、置信度、标签和模型原始结果。
- 每次识别同时查看当前页和下一页；跨页题只在起始页创建一次，并以多个 `question_regions` 保存不同页面上的独立范围。
- 同一试卷按顶层题号唯一保存；下一页候选题以及“（1）”等小问不会误建为新题，历史重复项会在升级时安全去重。
- 答案页通过 `answerUpdates` 按题号回填，不会被伪造为新题。
- 审核页可切换跨页题的来源页，拖动或缩放题目范围，并在“题目范围”和“题图裁剪”间切换。
- 教师可修改题号、题型、题干、选项、答案、解析、分值和标签，也可以手动补题。
- 调整题图范围后，由 Sharp 生成真实 JPEG 裁剪文件。
- 已审核题目支持后补答案：导入 PDF 或图片后按题号和题干匹配，并列出未匹配、低置信度和仍缺答案的题目。

## 题库与试卷库

- 已审核题目支持服务端分页，以及题干、答案、标签和来源全文检索。
- 可按题型、来源和知识点筛选，并导出 JSON 或 Markdown。
- 支持小学、初中、高中和学科范围切换；模型只能从对应范围的预制或教师扩充标签目录中选择标签。
- 试卷库支持全部试卷、根目录和多层文件夹浏览，以及全局搜索、排序、网格/列表视图、重命名、移动和删除。
- 组卷入口位于试卷库之前，组卷保存后自动进入试卷库，可继续编辑或打印。

## 组卷与输出

- 支持从题库选题、调整顺序、智能补齐到 100 分并自动保存试卷。
- 内置中考数学、高考数学、日常作业和课堂测试模板。
- 试卷按选择、填空、解答等板块排版，并在板块标题旁显示分值规则。
- 教师可修改板块、分值、注意事项和考生信息栏，并保存为个人模板。
- 题图可在整卷预览中缩放、水平或垂直平移，并自动显示题号图注。
- 服务端使用 Chrome、Edge 或 Chromium 生成可下载的 A4 PDF，可选择是否包含答案。

## 模型配置与安全

- 内置 OpenCode MiMo V2.5 Free，使用 OpenCode 公共凭据，无需个人账号或 API Key。
- 支持 Chat Completions、OpenAI Responses 和 Anthropic Messages 三种多模态协议。
- 可配置 API Base URL、模型名称、API Key 和超时时间，并使用真实图片测试连接。
- API Key 使用 AES-GCM 加密存入 SQLite，接口只返回脱敏值。
- Chat Completions 固定 `reasoning_effort: "none"`，Responses 固定 `reasoning.effort: "none"`，Anthropic Messages 不启用 thinking。
- 无法关闭推理的模型会在连接测试时明确判定为不兼容，不会静默启用 Thinking。

## 诊断、备份与恢复

- `/api/health` 提供运行状态检查，`npm run doctor` 检查本地依赖、数据库和浏览器环境。
- 备份包含 SQLite 一致性快照、原卷、分页图、裁剪图和本机密钥。
- 备份创建后立即执行 SHA-256 和 SQLite 完整性校验，也可以在之后单独复验。
- 恢复前要求停止应用，并保留原数据目录为 `data.pre-restore-*` 安全副本，便于回滚。
