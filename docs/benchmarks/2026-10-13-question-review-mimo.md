# MiMo 2.6 Flash 逐题审核实测

后续已完成 [21 题逐项复核与保存内容审核对照](2026-10-13-question-review-manual-audit.md)：旧审核通过题中确认 4 道实质问题漏报；不发送原卷的候选方案更省费用，但也出现误报。下文保留初次流程及账单记录。

日期：2026-10-13。用户明确授权真实 API 调用后，使用现有 `xiaomi/mimo-v2.6-flash` OpenRouter 配置完成一次整卷识别及逐题审核。模型、接口及加密凭据与正式库配置一致。

## 样本与执行方式

- 2020 年上海市宝山区高考数学二模试卷，18 页（含参考答案），21 题。
- 正式库已无可用原卷，使用 `tmp/openrouter-benchmark-20261012/` 保留的原卷和页面图片，在新目录 `tmp/mimo-question-review-20261013/` 创建数据库副本和新文档；未修改正式库的题目、队列或默认模型。
- 调用生产 `extractDocument` → 每题独立 `reviewExtractedQuestion` → `finalizeDocument`，无模拟响应，无人工修改识别结果，无自动重试。
- 识别 1 次，审核 21 次，共 22 次 HTTP 请求，全部成功；每次审核独立 system/user 两条消息，只带当前题转录和相关原卷页，无历史会话。
- 每题带 2–4 张原卷页图，审核并发上限 2，输出上限 16 Token；实际每次返回 2 Token，共 42 Token。
- 原卷使用整页图，因此图上可能同时出现邻题；没有发送邻题的识别文本。这样保留小符号和跨页内容，但会重复计费图片输入。

## 运行结果

整卷流程耗时 **112 秒**。21 题均落库并完成审核：

| 审核状态 | 题数 |
| --- | ---: |
| 没问题 | 17 |
| 有问题 | 4（第 5、11、17、21 题） |
| 失败、待处理、未审核 | 0 |

整卷识别模型调用耗时 93.396 秒；逐题审核与流式识别重叠执行，最后一题审核在识别调用结束后 15.783 秒完成。审核调用耗时中位数 7.128 秒，最长 30.263 秒。没有运行“不带审核”的对照组，因此不能把两个时间差解释为严格测得的新增总延迟。

这些是模型的二选一审核结果，不是人工核验后的准确率；本次没有评估漏报率、误报率，也没有让审核模型输出问题解释。

## 实际费用（美元）

22 次请求均取得 [OpenRouter generation 账单](https://openrouter.ai/docs/api/api-reference/generations/get-generation)，无费用缺失。以下使用服务商 `total_cost`，不是软件中的人民币估价。

| 环节 | 请求数 | 输入 Token | 输出 Token | 实际费用 USD |
| --- | ---: | ---: | ---: | ---: |
| 整卷识别 | 1 | 27,831 | 12,986 | $0.007532420 |
| 逐题审核（新增） | 21 | 86,136 | 42 | **$0.013053941** |
| 合计 | 22 | 113,967 | 13,028 | **$0.020586361** |

审核输入中报告了 352 个缓存 Token（输入总量的子集）。

- 新增审核约 **1.31 美分/卷**，平均 **$0.000621616/题**。
- 按此样本平均值线性外推，1,000 题审核约 **$0.62**；不是固定报价。
- 审核费用相当于本次识别费用的 **173.3%**，加审核后整卷费用约为识别单项的 **2.73 倍**。
- 输出已经很短；费用主要来自输入原卷图片和本题转录。仅缩短输出或 system prompt 不能消除图片的重复输入成本。
- OpenRouter 实际路由到 Xiaomi、Io Net、Novita、Makora、Venice；都使用指定 MiMo 模型。页数、题长、缓存、路由和价格变化会影响费用。

## 本地证据与复查

证据仅留在 Git 忽略的 `tmp/mimo-question-review-20261013/`：

- `benchmark.json`：原卷页面哈希、配置和模型目录。
- `results.json`：原有整卷识别汇总，其 `costUsd` 只统计识别调用。
- **`question-review-costs.json`**：本次识别和审核的完整分项账单、逐题状态、trace ID、耗时及 generation ID。
- `model-traces/`：脱敏请求、原始响应和结构校验记录。

费用汇总脚本可重复运行，仅读取账单，不重新生成：

```powershell
node --import ./server/register.mjs --import tsx scripts/summarize-question-review-benchmark.mjs tmp/mimo-question-review-20261013 --billing
```

验证：逐一核对 21 个独立题号、指定模型、两条消息、输出上限及严格二选一响应；核对 22 份账单；费用脚本通过 Node 语法检查和 ESLint。
