视觉原因：resource-management.css 强制搜索框 flex-basis:100%，筛选必定多行；globals.css 仍将题干截断为两行，数学内容可能被裁切；试卷名称无明确宽度/截断规则，状态混在来源副行。修正仅限定两个页面。

批量边界：题目每页 50 条；试卷当前结果无分页。混合操作并非跨接口事务，成功项移出选择，失败项保留供重试，明确显示成功/失败数量。已删除源文件的原卷不能再次删除，但仍可移动。

实施与验证补充：

- 实际点击发现旧的单份组卷删除带 `content-type: application/json` 却没有请求体，会被后端 JSON 校验拒绝。本次单条和批量组卷删除均发送有效空对象，浏览器实测通过。
- `MathText` 原先只支持 `$…$`；补齐 `$$…$$`、`\(…\)`、`\[…\]`，题库正文保留换行、不截断公式，题图与选项默认可读。共享渲染组件没有改变工作台布局。
- 题库组件：`components/QuestionBank.tsx`。试卷库组件：`components/PaperLibrary.tsx`。必要共享组件：`components/SelectionCheckbox.tsx`、`components/MathText.tsx`。样式只在 `app/resource-management.css` 的两个资源页面作用域内修改。
- 后端仅修改 `lib/question-bulk-actions.ts` 的题目删除引用保护；被引用题目导致整批拒绝、无部分删除，单元测试验证引用和题目均保留。无归档接口、平台题库数据源或批量跨资源事务新增。
