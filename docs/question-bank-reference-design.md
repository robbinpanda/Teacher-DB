## 拣题功能审计与映射

- 历史退化主要是入口与状态语义：旧题库用小按钮模拟复选框，没有半选和明确范围；组卷入口/排序藏在篮中，题干曾被两行截断；文件夹管理折叠但接口仍存在。试卷库历史未发现真正的多选实现，8036c99 是基于已有单条接口补齐批量能力，不将此前不存在的能力说成“恢复”。完整历史证据见 `resource-library-audit.md`。
- Git 8036c99 已恢复原生多选、当前页全选、批量移动/删除、试卷混选与删除引用保护；本轮不回退。3202cf8 的选题篮排序使用 `moveOrderedItem`，现有 QuestionBank 仍把篮子和批量操作绑在 selectedQuestions；筛选或分页会清空全部状态。
- 新设计分离管理选择与组卷篮：复选框用于本页临时管理，切换范围清空；单题/批量加入篮子按顺序去重，篮子保留跨分页、筛选、页面和刷新。只设一个可收起的篮子入口，面板负责排序、移除、导出、进入组卷。
- 现有保存机制是 PaperBuilder POST `/api/papers`，保存作品后可在试卷库继续编辑；未保存编排没有服务端草稿或选题篮。新增篮子只在当前浏览器按用户与教学范围持久保存题目 ID，明确标注“本机保存；进入编辑器后保存试卷”，不声称已经保存作品。
- 篮子恢复复用现有 `/api/exports/questions?format=json&ids=…` 读取真实、当前用户已审核题目，剔除失效题目；不缓存假题干，不新增后台模型或数据表。进入组卷仍使用现有 `/papers/new?ids=…` 与保存流程。新组卷页面仅补齐指定 ID 的读取，避免默认最近 2000 题窗口遗漏旧题，不重构编辑器。
- 知识点只有真实平面标签，没有父子层级。使用可搜索的左侧知识点导航，点击题目标签也能筛选；不编造树、章节或题量。个人文件夹作为独立管理区按需展开，不与知识点或平台分类混在一个导航层。
- 学科/学段复用现有教学范围；题型常驻，年级与来源选择紧凑组织。现有查询已支持 year、region、school、examType、textbook；只从真实 sources/facets 生成下拉选项。难度没有结构化字段与查询支持，不展示假难度筛选。
- 单题优先级：完整正文/公式/题图/选项 → 查看答案解析 → 独立加入篮子主按钮；编辑与变式仍可达。来源弱化但完整可查，知识点可点击。
- 个人文件夹新建、子文件夹、重命名、删除空文件夹和教学画像保留；批量删除仍使用原接口与二次确认、已有组卷引用保护。
- 平台资源服务仍未开放；保留基础题库下模卷/名校分类说明，不把个人来源冒充平台资源，不新增假筛选或假按钮。
- 试卷库现有原卷/作品分类、搜索、文件夹、混选移动/安全删除、单条审核/原卷查看/编辑/导出都保留，本轮只读其代码并跑回归。归档无接口，下一阶段也不应凭空添加。
