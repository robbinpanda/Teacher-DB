# 按题目隔离识别错误

更新：2026-10-13。流水线版本 `whole-document-candidates-v4`，数据库迁移版本 5。

## 当前行为

- 一道题的 JSON 损坏不再中断整卷：解析器在下一条事件边界重新同步。只尝试补一个外层括号或修正无效反斜线转义；恢复后仍必须人工核对，保留原始文本，不推测题干、答案和数学结论。
- 无法解析但能确定题号的记录成为该题的空白待审核项。按原 PDF 独立核对题数（无可靠原卷清单时用模型声明）补出缺失题号的待补录项；不把占位项当成识别成功的内容。
- 图片数量小于匹配数时保留全部有效图片，记录数量矛盾；缺图、非法候选、图片字段错误按本题反馈。无法定位的框不生成虚构裁剪。
- 文本中的异常控制字符及不成对的花括号标记为本题识别异常；没有自动纠正数学内容。这不是完整的 LaTeX 或数学正确性校验。
- 重复 `meta`、`done` 不再推翻已经保存的题目；重复题目保留首次结果并要求核对该题。无法确定题号的原始事件保存在识别运行诊断中，不猜测归属。
- 有异常的试卷正常进入审核。正常题可以先入库；异常题必须修正内容并明确标记已核对，缺图还需单独确认处理。空白题干不能入库。
- 收尾不再删除本次未返回的既有题目，也不重复覆盖逐题保存的结果。失败占位项不覆盖已有草稿内容，已审核题目不被本次模型返回覆盖。
- 网络、文件存储、数据库、租约等基础设施错误仍会失败或由队列重试；这些错误不能伪装成某一道题的内容问题。完全没有可定位题目和可靠题数的输出仍报识别失败。

## 保存与审核

新增 `questions.extraction_issues_json`，对应 API 的 `extractionIssues`，记录原因、代码及适用时的原始返回。已有 `missing_images_json` 继续承载缺图和图片数量核对事项。

审核页面显示“本题识别异常”，可展开原始返回；教师修正后通过 `extractionIssuesResolved=true` 明确确认。后端以数据库中尚未解决的异常为准，不能只清空客户端列表绕过校验。确认后清空待处理列表，`extraction_runs.raw_json` 中逐题 `_extractionIssues` 仍保存本次识别的诊断证据。

迁移仅增加列，旧数据默认 `[]`，不修改旧迁移校验值。本次未批量改写昨天测试的数据库，也未重新调用付费模型。

## 后续方向

1. 为人工确认增加异常版本号，避免多个打开的审核窗口用旧确认覆盖新诊断。
2. 提供单题重新识别入口与版本比较，明确保留人工修改；本次没有自动重跑或增加付费调用。
3. 将无法归属题号的运行级异常集中展示在审核页顶部，并增加按异常类型筛选。
4. 对裁剪失败增加独立图片重试；当前存储或图像处理异常仍作为基础设施失败。
5. 在固定内容基准集上继续评分模型，分别统计内容质量、需人工修复比例与请求可用性，避免把容错后“可进入审核”误认为内容全部正确。
