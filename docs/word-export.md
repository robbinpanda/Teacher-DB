# Word 导出

组卷页的下载按钮旁可选择 PDF 或 Word。选 Word 时，「下载试卷」和「解析答案」得到 `.docx`，选择会记在浏览器里，下次仍是 Word。

## 导出的是什么

- **公式是 Word 原生公式**，在 Word 2007 以上直接双击编辑，不需要安装任何插件。
- **文字、选项、题图都是普通内容**：题干是普通段落，选项用制表位对齐，题图是嵌入图片，解答题下方是空行，老师可以直接增删。
- **版式跟随试卷模板**：纸张、页边距、字号、标题、考生信息栏、注意事项、板块标题、题号样式、分值、双栏、页脚页码。
- **只导出 `.docx`**。存成旧的 `.doc` 时 Word 会把原生公式变成图片。

## 需要 MathType 格式时

导出的不是 MathType 对象。装有 MathType 的老师打开文档后，用 Word 里 MathType 选项卡的「转换公式」，把「Word 公式」批量转成 MathType 公式即可。

没有直接生成 MathType 对象，是因为它是带私有二进制格式的嵌入对象，没有可靠的开源写入库；写错时老师双击会打不开。

## 实现

| 文件 | 作用 |
| --- | --- |
| `lib/word-math.ts` | LaTeX → Word 公式。先用与屏幕渲染相同的 KaTeX 和宏得到 MathML，再映射为 Word 公式结构 |
| `lib/word-export.ts` | 组装整份文档，纯函数，图片由调用方传入 |
| `server/http/handlers/papers/[paperId]/docx/route.ts` | `GET /api/papers/{id}/docx`，加 `?answers=1` 导出解析答案 |

几处专门处理过的地方：

- **行内分式不缩小**：Word 会把行内分式压到正文的 70%。导出时给分子分母设置放大的字号，使其与正文等高，和屏幕上一致。
- **括号随内容伸缩**：`\left( \right)`、分段函数的大括号都导出为可伸缩的定界符。
- **`lim` 的下标放在正下方**，`sin`、`cos` 等函数名为正体并带作用对象。
- **多行对齐**（`aligned`）保留等号对齐。
- **填空横线**导出为带下划线的空格。
- **WebP 题图**会转成 PNG，因为 Word 不支持嵌入 WebP。

## 导出后的提示

- **公式无法解析**：屏幕上显示「公式待核对」的公式，在文档里保留为黄色高亮的 `$...$` 原文，下载后页面会提示题号。
- **题图读不到**：页面提示题号，文档里该处没有图片。

## 验证

```bash
npm test
```

```bash
npm run word:verify
```

`word:verify` 启动一个独立的接口服务（端口 3291，临时数据目录，不调用模型），创建一份带公式、选项和题图的试卷并下载检查。在装有 Word 的 Windows 上加 `-- --open-in-word`，会用真实的 Word 打开两份文件、核对公式个数，并在 `tmp/word-export-check/` 生成 PDF 供目视检查。
