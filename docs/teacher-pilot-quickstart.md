# 教师试用环境

试用地址为 `http://localhost:3070/studio`，稳定题库仍在 `http://localhost:3050`。试用页面顶部显示黄色“试用副本”提示。两边的数据分别保存：在试用版编辑、标注或生成的内容不会自动写回稳定题库。需要保留的作品可先导出 PDF；试用目录本身不要删除。

## 一次完整试用

1. 先在侧栏选择学段、学科，再进入“备课工作台”。三角函数示例应选择高中数学。
2. 选择试卷、讲义或校本教辅，输入实际要求。例如：“制作三角函数周期专题讲义，2 道例题、4 道练习，由易到难，包含公式适用条件和易错点。”选择编写与审校模型后创建。
3. 检查提取的要求、考点范围和题量核算，再确认大纲。需要澄清的问题先处理；不能把模型自行补充的条件当成原要求。
4. 生成后逐章查看来源、选题理由、正文、审校问题和缺题。无合适题时保留缺口，可修改配额、换题或重做本章。模型未发现问题不代表数学一定正确。
5. 编辑内容并核对后采用章节，最后生成作品并导出 PDF。解答题仍保留半页独立作答区。章节历史可预览、恢复旧大纲及正文；恢复后需重新核对。
6. 整卷变式从原试卷创建，逐题核对与原题的对应关系、答案和解析，通过后采用。首选不合格时系统会继续审查已有备用题，只有通过全部复核门槛的题才能供采用；全部候选不合格则保留失败，可单独重试。

完整三角函数的 14 章、84 题规划已做真实模型验证；完整正文、真实选题质量和整卷变式质量尚未验收。建议先用一个专题走通上述流程，再扩大范围。候选题里的文字线索不等于已确认标签，难度与知识点需要核对。

生成过程中可点“暂停后续生成”。当前请求返回的有效结果会保存，后续调用等待继续；刷新页面也能找回已保存批次。失败时点“继续上次生成”，从完成的选题进度接着做；题目、标签、章节计划或模型设置变化后会重新比较。选题已结束而正文失败时，继续会直接编写正文。尚未返回的请求无法保证恢复，可能需要重新执行这一批。

章节中的“逐题答案与讲解核验”展示模型复算答案和依据，并注明对应原题。模型也可能算错，需对照题干核对；若审校字段和解释明确矛盾，系统会停止自动处理并保留正文。原题答案错误时应修复题库或替换选题，不能只改讲义讲解后沿用错误的参考答案。

## 维护与重启

本机本轮已部署代码快照 `tmp/teacher-pilot/trial-release-20261024`，使用数据副本 `tmp/teacher-pilot/trial-data-20261024-v2`。从项目根目录执行 `node tmp/start-teacher-pilot.mjs` 可复用这份副本启动；该本机启动文件和数据不上传 GitHub。以下步骤用于新建另一份环境，须换用尚不存在的目录。

创建副本时，先从项目根目录运行：

```powershell
node scripts/prepare-pilot.mjs tmp/teacher-pilot/trial-data-YYYYMMDD
```

目录必须不存在。脚本使用 SQLite 在线备份，逐个核对附件 SHA-256，并检查数据库引用的附件、数据库完整性及外键；完成后才写入副本标记。原库已有失效的来源图路径、但对应裁剪图全部完整时，在 `pilot-copy.json` 的 `warnings` 中记录并保留原记录；原卷、页面或裁剪图缺失仍会阻止完成。复制期间原库仍可使用，但不要同时删除原卷或修改附件。若检查失败，保留失败副本用于排查，使用新的目录重新创建。

从准备好的代码快照根目录启动，数据路径必须为绝对路径：

```powershell
$env:JIANTI_PILOT_DATA_DIR = 'C:\完整路径\trial-data-20261024'
node scripts/run-pilot.mjs --build
```

启动器固定使用 3070 网页和 3170 API，仅监听本机；使用独立构建目录与日志。复制来的待运行识题/备课/标注任务已暂停，PDF 预处理任务标为失败待手动重试，旧进程心跳已清除。试用中的新任务只有操作后才提交。PDF 上传使用浏览器分页，不复用稳定版的后台处理服务。

持续运行请用 Windows 隐藏进程，并将输出重定向到本地日志。通过 `.runtime/local-3070.json` 的实例 ID 与 `/api/ready` 匹配确认所属进程后才能停止；不能根据旧 PID 文件停止未知进程。重启使用同一副本目录，不重新复制。不要在运行中的代码快照切换分支或覆盖构建；升级时停试用服务，准备新代码快照，再用保留的副本启动。正式库不参与试用版数据库迁移。
