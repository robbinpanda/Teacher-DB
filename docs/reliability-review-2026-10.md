## 论文依据和实现边界

依据用户本地 `寻找灵感/archive/临时与缓存/pdfs` 中保存的论文全文：

- `text/08_eqpr.txt`：*From Objectives to Questions: A Planning-based Framework for Educational Mathematical Question Generation*，arXiv:2506.00963v1。采用目标、先修知识、变化策略、评价与修订的组织方式。这里实现固定有界流程，没有复现论文的 MCTS 搜索或训练实验。
- `remaining/text/27_distractors.txt`：*Generating Plausible Distractors via Student Choice Prediction*。命题计划显式列出误区，选择题要求验证干扰项；没有训练学生选择预测器或 DPO 模型。
- `remaining/text/29_qgsms.txt`：*QG-SMS: Enhancing Test Item Analysis via Student Modeling and Simulation*，arXiv:2503.05888v2。将难度与误区说明展示为模型预测，不能把文本质量或模型评分当作实际区分度、难度或学习效果。

审校模式固定四次模型调用：计划、生成、审校修订、最终复核。快速模式两次调用：计划、生成，仍需人工认真核对。模型失败不会偷偷降级为审校通过，也不会无限重试。相同模型的独立上下文并不等于统计独立或正确性证明。

## 部署边界

本地仍默认单教师空间 `local-demo`。公网多用户部署需要可信认证代理，不能信任客户端自行提供的身份头；本次没有引入新的登录系统。模型结果的真实性仍须用真实试卷和真实教师复核校准，模拟模型测试只验证程序流程与失败边界。


## Skill 验证边界

默认规则按年级识读阶段与学科特征组合，数学另有逐年级概念提示。它们不是经过各地教材逐条认证的课程标准；小学物理等组合明确按拓展材料处理。个人模型生成结果须有 `name`、`description` 的 Markdown/YAML 头，最多12000字。

样例输入目前为单张图片；正式题库导入继续使用 PDF。试识别只验证这一张样例，不能代表其他版式和整卷识别准确率。模型识别、复核与改进分别使用独立上下文，但不宣称由此证明教学有效性。教师仍应在正式审核页检查新试卷。

新增 `npm run skills:verify` 在隔离临时数据库和本地模拟模型上验证上传到正式识题的完整流程，不读取或修改真实题库，也不调用付费模型。
